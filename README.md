LlanquihueTourApp

Programa en Java que lee un archivo de texto con las personas del tour (guías y operadores), las guarda en una lista y las muestra por consola.

Estructura
LlanquihueTourApp
└── src/main
    ├── java/cl/duoc/llanquihuetour
    │   ├── model/Tour.java
    │   ├── data/GestorPersonas.java
    │   └── ui/Main.java
    └── resources/tour.txt


Ejemplo:

Harry Potter; Guia; 56912345678; Puerto Varas
Cómo ejecutar
Abrir el proyecto en IntelliJ.
Abrir Main.java y pulsar el botón verde Run.
